AllPlayer Support

If you run into playback, import, LAN connection, live caching, stream management, or file management issues, start with the notes below or contact us by email.

Support emailplayersupport.arco@gmail.com

Before Contacting Us

Helpful details to include in your email

Device and system

Include your device model, iOS / iPadOS / visionOS version, and AllPlayer version.

Playback source

Tell us whether the issue happens with local files, Photos, SMB, WebDAV, FTP, m3u8, HLS, live streams, or web videos.

Steps and context

Share steps to reproduce, screenshots, file format, stream type, server settings, or any visible error message.

Local videos do not play

Check whether the file is damaged and try copying it into AllPlayer's local folder before playback. For uncommon codecs or containers, send the format and symptoms so we can investigate.

Photos library is not accessible

Open system Settings and check AllPlayer's Photos permission. If you granted limited access, make sure the target video or image is included.

SMB, WebDAV, or FTP connection fails

Confirm the server address, port, username, password, and path. Also check firewall, sharing permissions, router isolation, and whether your device can reach the server network.

m3u8, HLS, or live streams are unstable

Online streams depend on source availability, network quality, and stream format. Try another network, re-add the URL, check whether the link expired, or switch to a more stable quality.

Live stream caching did not finish

Make sure the device has enough storage and the network stays stable during playback. Some sources may restrict or prevent full caching.

Share extension import fails

Confirm that the source app provides an accessible video file or valid URL. Some apps share temporary links that need to be shared again after they expire.

AirPlay or full screen behaves unexpectedly

Check that the receiving device is available, on the same network, and updated. Behavior can vary by system player capabilities, external device, and source format.

Feature requests

Email your use case, expected behavior, and device details. We especially welcome feedback around personal libraries, NAS playback, stream management, live caching, and visionOS viewing.

Before Contacting Us

邮件中建议包含的信息

设备与系统

请说明你的设备型号、iOS / iPadOS / visionOS 版本，以及 AllPlayer 版本号。

问题场景

请描述问题发生在本地文件、照片图库、SMB、WebDAV、FTP、m3u8、HLS、直播流还是网页视频中。

可复现步骤

请尽量提供操作步骤、错误提示截图、视频格式、流地址类型或服务器配置方式。

本地视频无法播放怎么办？

请确认文件没有损坏，并尝试将文件复制到 AllPlayer 的本地目录后再播放。如果是较少见的编码或封装格式，可以提供文件格式、编码信息和错误表现。

无法访问照片图库？

请前往系统“设置”中检查 AllPlayer 的照片访问权限。若你只授予了部分照片访问权限，请确认目标视频或图片已包含在授权范围内。

SMB、WebDAV 或 FTP 连接失败？

请确认服务器地址、端口、用户名、密码和路径是否正确，同时检查防火墙、共享权限、路由器隔离设置和网络可达性。

m3u8、HLS 或直播流播放不稳定？

在线视频流依赖源站可用性、网络质量和流媒体格式。你可以尝试切换网络、重新添加 URL、检查链接是否过期，或选择更稳定的清晰度。

直播缓存没有保存成功？

请确认设备有足够可用存储空间，并保持播放过程中的网络连接稳定。某些流媒体源可能因为协议、权限或源站限制而无法完整缓存。

分享扩展导入失败？

请确认来源 App 提供的是可访问的视频文件或有效 URL。部分 App 可能只分享临时链接，链接失效后需要重新从来源 App 分享。

AirPlay 或全屏播放异常？

请确认接收设备可用、处于同一网络，并且系统版本较新。全屏、投屏和画面比例行为可能受到系统播放器能力、外接设备和视频源格式影响。

如何反馈功能建议？

欢迎通过邮件发送你的使用场景、期望功能和设备信息。我们会优先关注个人媒体库、NAS 播放、流媒体管理、直播缓存和 visionOS 观看体验相关的改进。
